Design direction Calm Precise — the trustworthy instrument. Restraint is the craft: calm neutral chrome, colour spent only where it carries meaning, and every interactive component shipping all of its states. Every value on this page comes from design/tokens.css and is consumed by design/components.css; no component hard-codes a colour, size or duration.

The CLI contract

  • 0 Count printedstdout carries the integer and a trailing newline, nothing else success
  • 1 Unreadable inputwordcount: missing.txt: no such file i/o error
  • 2 Bad command lineusage: wordcount [-h] [--version] FILE usage error

$ count=$(wordcount notes/tide.txt) && echo "the file holds $count words"

04

States and measurements

Default, hover, active, focus-visible and disabled are all defined in design/components.css; focus uses a crisp 2px --focus-ring offset by 2px. Motion is a precision tick: 160ms ease-out, 300ms data flash, both disabled under prefers-reduced-motion.
